# Festival Best Wishes（个性化节日祝福语助手）

## 这是什么
一个跑在 AI agent（智能体）里的技能（skill）。你说要写节日祝福，它不直接甩套话，而是像朋友一样**一步步问你**（哪个节日→给谁写→怎么称呼→你们之间的小事→想不想让对方回复），问完再替你写出**只有你俩才发得出**的祝福语，每条单独成块、一键复制就能发。

## 有什么作用
- 🎯 **先问后写**：用 5 步问答挖出你们之间的真实交集，拒绝"阖家团圆万事如意"式群发
- ✍️ **一次 3 条**：稳重款 / 具体款 / 轻松款各一条，挑最顺手的发
- 📋 **单句可复制**：每条祝福语独立成块，点开即复制，粘贴到微信就能发
- 👔 **看人下笔**：领导客户稳重无表情、长辈只关心身体、好友用你俩的梗——写法随对象自动切换
- ⏱️ **短小真诚**：每条卡在 50 字以内，越少越具体越打动人
- 🌙 **多节日通用**：中秋、春节、端午、教师节、生日……一套流程全适用
- 💌 **贴心收尾**：帮你写完，最后还送你本人一条节日祝福

## 能帮助谁
一到节日就被"群发祝福"为难的人：要给客户/领导发又怕像机器人的职场人、通讯录里长辈朋友一堆却只会复制粘贴的社恐、以及任何想让祝福显得走心、不想发出去石沉大海的人。手机上就能操作。

## 解决什么问题
| 痛点 | 本技能的机制 |
|---|---|
| 🤖 群发祝福没人回，等于白发 | 用问答逼出"你们之间真实的小事"，祝福立刻不像群发 |
| 😶 只会"中秋快乐"，翻来覆去那几句 | 按对象分五类写法，落笔各不同 |
| 🧩 发给谁都不知措辞 | 领导/长辈/好友/客户/潜客对照表，语气分寸自动匹配 |
| 📎 复制粘贴麻烦 | 每条祝福语独立成块，单句一键复制 |
| 🎭 用了 AI 却满是成语排比的机器味 | 硬规则：≤50字、不堆成语排比、落到具体细节 |

## 证据（真实运行数据）
待首月运行数据。本技能方法论源自「AI 写走心祝福」实践总结，核心主张：AI 不缺文采，缺的是你与对方真实的交集；字数越少越好，越具体越真诚。

## 功能核心点
1. **五问采集法**——节日/对象/称呼/交集小事/期望反应，逐题问答，一次只问一个，答完才动笔
2. **对象分类优先级**——期待回复的（客户领导）值得多花两分钟；家人朋友提醒一句"电话更暖"；潜在客户随缘别硬凑
3. **交集小事是命门**——答不出细节会追问引导，宁可多问一轮也不用套话填空
4. **写法对照表**——五类对象各有硬性写法要点（如领导客户禁 emoji、长辈禁特殊符号）
5. **三条不重样**——同一次生成稳重/具体/轻松三款，全部含你给的真实细节
6. **交付即复制**——代码块分条，块内无杂字，点评放块后
7. **通用收尾祝福**——本轮写完后送用户本人一条当节祝福，不署名、不写死人名

## 注意事项
- **首次使用先完成一次 DIKO 授权**：对 agent 说出触发语（如"帮我写条中秋祝福"），agent 会先说明用途再引导注册（凭据只存你本机），之后每天自动校验、不再打扰
- **纯对话技能**：不读写你的本地文件，只靠聊天问答生成文字，无数据落盘
- **依赖 agent 能力**：需支持加载 skill 文件、多轮对话、Markdown 渲染（详见「使用方法.text」）
- **诚实边界**：它负责把你想表达的东西写成得体的话，但"你们之间有什么故事"仍要你亲口提供——细节越真，祝福越走心
- **发送前自查**：复制到微信前自己通读一遍，删掉任何代码块格式符号
